# Portfolio Bruno Couceiro

Portfolio personal de Bruno Couceiro, desarrollador fullstack. Web en Angular 21 (standalone) con los 3 casos de estudio en producción, CV descargable y contacto.

## Desarrollo

```bash
npm install
ng serve
```

Navega a `http://localhost:4200/`.

## Build

```bash
ng build
```

El resultado se genera en `dist/` para desplegar en Vercel.
